# 🔴 Pokedex 

Uma Pokedex interativa e moderna construída com HTML, Tailwind CSS e JavaScript vanilla, consumindo a [PokeAPI](https://pokeapi.co/).

![Preview](https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/25.png)

## ✨ Funcionalidades

### Core
- 📋 **Grid de Pokémons** - Exibe os 151 Pokémons da 1ª geração
- 🔍 **Busca em tempo real** - Pesquise por nome ou número
- 📄 **Modal de detalhes** - Visualize status, tipos, descrição e cadeia evolutiva
- ♾️ **Paginação** - Carregue mais Pokémons conforme necessário

### Avançadas
- 🏷️ **Filtros por tipo** - Filtre por Fogo, Água, Grama, etc.
- ❤️ **Sistema de favoritos** - Salve seus Pokémons favoritos (persistente)
- 🔊 **Sons dos Pokémons** - Ouça o grito de cada Pokémon
- 🌙 **Modo escuro** - Alterne entre tema claro e escuro
- 🎮 **Efeito 3D** - Cards com efeito holográfico ao passar o mouse

### Mini-games
- ❓ **Quem é esse Pokémon?** - Adivinhe o Pokémon pela silhueta
- ⚔️ **Batalha Pokémon** - Escolha 2 Pokémons e descubra o mais forte
- 📊 **Comparador de Status** - Compare stats de 2 Pokémons lado a lado

## 🚀 Tecnologias

- **HTML5** - Estrutura semântica
- **Tailwind CSS** (CDN) - Estilização moderna e responsiva
- **JavaScript ES6+** - Lógica e interatividade
- **PokeAPI** - Dados dos Pokémons
- **VanillaTilt.js** - Efeito 3D nos cards
- **LocalStorage** - Persistência de favoritos e preferências

## 🎮 Como jogar

### Quem é esse Pokémon?
1. Clique no botão **"Jogar"** (amarelo)
2. Tente adivinhar o Pokémon pela silhueta
3. Acumule uma sequência de acertos!

### Batalha Pokémon
1. Clique no botão **"Batalha"** (vermelho)
2. Jogador 1 escolhe seu Pokémon
3. Jogador 2 escolhe seu Pokémon
4. Clique em **"LUTAR!"**
5. Vence quem tiver mais status superiores!
