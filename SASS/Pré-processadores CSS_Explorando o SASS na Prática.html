🤔 O que são Pré-processadores CSS?

Pré-processadores CSS são ferramentas que estendem as capacidades do CSS tradicional, permitindo usar variáveis, funções, aninhamento e muito mais. O código é então compilado para CSS puro que os navegadores entendem.

❌ CSS Tradicional

.header { color: #333; }
.header .nav { color: #333; }
.header .nav a { color: #333; }

✅ Com SASS

$cor-texto: #333;

.header {
  color: $cor-texto;
  .nav {
    color: $cor-texto;
    a { color: $cor-texto; }
  }
}

Módulo 2

🚀 Primeiros Passos com o SASS

📝 Sintaxes: SASS vs SCSS

O SASS possui duas sintaxes diferentes. Você pode escolher a que preferir!

SASS (indentação)

$cor-primaria: #3498db

.botao
  background: $cor-primaria
  padding: 10px
  &:hover
    background: darken($cor-primaria, 10%)

Sem chaves { } nem ponto-e-vírgula ;

SCSS (similar ao CSS)

$cor-primaria: #3498db;

.botao {
  background: $cor-primaria;
  padding: 10px;
  &:hover {
    background: darken($cor-primaria, 10%);
  }
}

✅ Mais popular - similar ao CSS

💡 Dica: Use SCSS se você já conhece CSS! É mais fácil migrar projetos existentes.

📦 Como Instalar o SASS

Via NPM (Node.js)

# Instalar globalmente
npm install -g sass

# Ou como dependência do projeto
npm install --save-dev sass

Depois de instalado, compile com:

sass input.scss output.css

Download Direto

1. Baixe em: sass-lang.com/install

2. Extraia o arquivo

3. Adicione ao PATH do sistema

Ideal para quem não usa Node.js

Extensão Live Sass Compiler

1. Abra o VS Code

2. Vá em Extensions (Ctrl+Shift+X)

3. Procure por "Live Sass Compiler"

4. Instale e clique em "Watch Sass" na barra inferior

✨ Mais fácil! Compila automaticamente ao salvar

⚙️ Compilando SASS para CSS

1

Crie um arquivo .scss

Exemplo: styles.scss

2

Execute o comando de compilação

sass styles.scss styles.css
3

Use o modo watch para auto-compilação

sass --watch styles.scss:styles.css

Agora toda alteração será compilada automaticamente!

Módulo 3

⚡ Principais Recursos do SASS

💾 Variáveis

Armazene valores que você usa repetidamente (cores, fontes, tamanhos, etc.) 

// Definindo variáveis
$cor-primaria: #3498db;
$cor-secundaria: #2ecc71;
$espacamento: 16px;

// Usando as variáveis
.botao {
  background-color: $cor-primaria;
  padding: $espacamento;
  
  &:hover {
    background-color: darken($cor-primaria, 10%);
  }
}
💡 Vantagem: Altere a cor em um único lugar e ela muda em todo o projeto!

🪆 Nesting (Aninhamento)

Aninhe seletores para refletir a hierarquia do HTML 

.nav {
  background: #333;
  
  ul {
    list-style: none;
    
    li {
      margin: 0 10px;
      
      a {
        color: white;
        
        &:hover {  // & = seletor pai
          color: #3498db;
        }
      }
    }
  }
}
⚠️ Cuidado: Não aninhe mais de 3-4 níveis!
Módulo 4

🔧 Lógica e Depuração com SASS

🧮 Expressões Literais e Operações

SASS permite realizar operações matemáticas diretamente no CSS! 

// Operações Matemáticas
$largura-base: 1000px;
$colunas: 4;
$espacamento: 20px;

.container {
  width: $largura-base;
}

.coluna {
  // Divisão
  width: ($largura-base / $colunas) - $espacamento;
  
  // Multiplicação
  padding: $espacamento * 2;
  
  // Adição e Subtração
  margin: ($espacamento / 2) + 5px;
}

// Operações com cores
$cor-base: #3498db;

.botao {
  background: $cor-base;
  
  &:hover {
    // Escurecer 15%
    background: darken($cor-base, 15%);
  }
  
  &:active {
    // Clarear 10%
    background: lighten($cor-base, 10%);
  }
}

// Concatenação de strings
$prefixo: 'icon';
$tamanho: 'large';

.#{$prefixo}-#{$tamanho} {  // Gera: .icon-large
  font-size: 32px;
}
💡 Operadores disponíveis:
  • + Adição
  • - Subtração
  • * Multiplicação
  • / Divisão (use parênteses!)
  • % Módulo (resto da divisão)

🔀 Estruturas Condicionais (@if, @else)

Use condicionais para aplicar estilos baseados em variáveis ou parâmetros 

// Exemplo 1: Tema baseado em variável
$tema: 'escuro';

.site {
  @if $tema == 'escuro' {
    background: #1a1a1a;
    color: #fff;
  } @else if $tema == 'claro' {
    background: #ffffff;
    color: #333;
  } @else {
    background: #f5f5f5;
    color: #666;
  }
}

// Exemplo 2: Função com condicionais
@function tamanho-responsivo($tamanho) {
  @if $tamanho == 'pequeno' {
    @return 14px;
  } @else if $tamanho == 'medio' {
    @return 16px;
  } @else if $tamanho == 'grande' {
    @return 20px;
  } @else {
    @return 16px; // padrão
  }
}

.texto-pequeno {
  font-size: tamanho-responsivo('pequeno');
}

// Exemplo 3: Verificar se variável existe
$borda-ativa: true;

.card {
  padding: 20px;
  
  @if $borda-ativa {
    border: 1px solid #ddd;
    border-radius: 8px;
  }
}

🔁 Estruturas de Repetição (@for, @each, @while)

Loops são perfeitos para gerar múltiplas classes ou estilos repetitivos

Loop @for - Contar de 1 até N

// Gerar classes de colunas (col-1, col-2, col-3...)
@for $i from 1 through 12 {
  .col-#{$i} {
    width: percentage($i / 12);
  }
}

// CSS Gerado:
// .col-1 { width: 8.33333%; }
// .col-2 { width: 16.66667%; }
// .col-3 { width: 25%; }
// ... até .col-12 { width: 100%; }

// Exemplo 2: Margens incrementais
@for $i from 1 through 5 {
  .margin-#{$i} {
    margin: #{$i * 8}px;
  }
}

// Gera: .margin-1 (8px), .margin-2 (16px), etc.

Loop @each - Iterar sobre listas

// Lista de cores para temas
$cores: (
  'primaria': #3498db,
  'secundaria': #2ecc71,
  'perigo': #e74c3c,
  'alerta': #f39c12,
  'info': #16a085
);

@each $nome, $cor in $cores {
  .btn-#{$nome} {
    background-color: $cor;
    
    &:hover {
      background-color: darken($cor, 10%);
    }
  }
}

// Exemplo 2: Ícones de redes sociais
$redes-sociais: facebook, twitter, instagram, linkedin;

@each $rede in $redes-sociais {
  .icon-#{$rede} {
    background-image: url('img/#{$rede}.svg');
  }
}

Loop @while - Enquanto condição for verdadeira

// Criar headings com tamanhos decrescentes
$i: 6;

@while $i > 0 {
  h#{$i} {
    font-size: #{2 + $i * 0.5}em;
    margin-bottom: #{$i * 5}px;
  }
  $i: $i - 1;
}

// Gera:
// h6 { font-size: 5em; margin-bottom: 30px; }
// h5 { font-size: 4.5em; margin-bottom: 25px; }
// ... até h1
⚠️ Cuidado: Loops podem gerar muito CSS. Use com moderação!

⚙️ Funções e Módulos Nativos

SASS possui funções built-in poderosas para manipular cores, strings, números e mais!

🎨 Funções de Cor

$cor: #3498db;

// Manipulação de luminosidade
darken($cor, 20%)    // Escurece
lighten($cor, 20%)   // Clareia

// Saturação
saturate($cor, 30%)  // Mais saturado
desaturate($cor, 30%) // Menos saturado

// Transparência
rgba($cor, 0.5)      // 50% opaco
opacify($cor, 0.3)   // Aumenta opacidade
transparentize($cor, 0.3)

// Misturar cores
mix(#ff0000, #0000ff, 50%)

// Inverter
invert($cor)

// Escala de cinza
grayscale($cor)

🔢 Funções de Número

// Arredondamento
round(3.7)      // 4
ceil(3.2)       // 4
floor(3.7)      // 3

// Valor absoluto
abs(-15)        // 15

// Mínimo e máximo
min(10, 20, 5)  // 5
max(10, 20, 5)  // 20

// Porcentagem
percentage(0.5) // 50%

// Aleatório
random(100)     // 1-100

📝 Funções de String

// Comprimento
str-length("Hello")        // 5

// Converter para maiúsculas/minúsculas
to-upper-case("sass")      // "SASS"
to-lower-case("SASS")      // "sass"

// Inserir string
str-insert("Hello", " World", 6)  // "Hello World"

// Substituir
str-replace("Hello World", "World", "SASS")  // "Hello SASS"

🐛 Diretivas de Depuração (@warn, @error, @debug)

Ferramentas essenciais para debugar e validar seu código SASS 

// @debug - Exibe valores no console durante compilação
$largura: 1200px;
@debug "Largura do container: #{$largura}";

// @warn - Avisos (não param a compilação)
@mixin botao($tamanho) {
  @if $tamanho < 10px {
    @warn "Tamanho muito pequeno! Mínimo recomendado: 10px";
  }
  
  font-size: $tamanho;
  padding: $tamanho / 2;
}

// @error - Erros (param a compilação)
@function dividir($a, $b) {
  @if $b == 0 {
    @error "Não é possível dividir por zero!";
  }
  @return $a / $b;
}

// Exemplo prático: Validação de tema
@mixin tema($tipo) {
  @if not index(('claro', 'escuro', 'auto'), $tipo) {
    @error "Tema '#{$tipo}' inválido! Use: claro, escuro ou auto";
  }
  
  // Aplicar tema...
}
📌 Quando usar cada um:
  • @debug: Verificar valores durante desenvolvimento
  • @warn: Alertar sobre uso não recomendado
  • @error: Impedir uso incorreto que quebraria o site

🚀 Convertendo um Projeto CSS para SASS

📁 Passo 1: Organizando os Módulos

A primeira etapa é criar uma estrutura de pastas organizada

📁 sass/
├── 📁 abstracts/
│ ├── _variables.scss
│ ├── _mixins.scss
│ └── _functions.scss
├── 📁 base/
│ ├── _reset.scss
│ ├── _typography.scss
│ └── _utilities.scss
├── 📁 components/
│ ├── _buttons.scss
│ ├── _cards.scss
│ ├── _forms.scss
│ └── _modals.scss
├── 📁 layout/
│ ├── _header.scss
│ ├── _footer.scss
│ ├── _sidebar.scss
│ └── _grid.scss
├── 📁 pages/
│ ├── _home.scss
│ └── _about.scss
└── main.scss
// main.scss - Arquivo principal que importa tudo

// 1. Abstrações (variáveis e ferramentas)
@import 'abstracts/variables';
@import 'abstracts/mixins';
@import 'abstracts/functions';

// 2. Base (reset e estilos globais)
@import 'base/reset';
@import 'base/typography';
@import 'base/utilities';

// 3. Layout (estrutura da página)
@import 'layout/header';
@import 'layout/footer';
@import 'layout/sidebar';
@import 'layout/grid';

// 4. Componentes (elementos reutilizáveis)
@import 'components/buttons';
@import 'components/cards';
@import 'components/forms';
@import 'components/modals';

// 5. Páginas (estilos específicos)
@import 'pages/home';
@import 'pages/about';

Converta seletores CSS planos para a estrutura aninhada do SASS

        color: $cor-primaria;
      }

        font-weight: bold;
        border-bottom: 2px solid $cor-primaria;
      }
    }
  }
}

🎨 Passo 3: Isolando Trechos com Mixins

Identifique padrões repetidos e crie mixins reutilizáveis

❌ CSS com Repetição

.card {
  display: flex;
  justify-content: center;
  align-items: center;
}

.modal {
  display: flex;
  justify-content: center;
  align-items: center;
}

.botao-grande {
  padding: 20px 40px;
  font-size: 18px;
  border-radius: 8px;
}

.botao-pequeno {
  padding: 10px 20px;
  font-size: 14px;
  border-radius: 4px;
}

✅ SCSS com Mixins

// Mixin para centralizar
@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

.card {
  @include flex-center;
}

.modal {
  @include flex-center;
}

// Mixin parametrizado
@mixin botao($tamanho: 'medio') {
  @if $tamanho == 'grande' {
    padding: 20px 40px;
    font-size: 18px;
    border-radius: 8px;
  } @else {
    padding: 10px 20px;
    font-size: 14px;
    border-radius: 4px;
  }
}

.botao-grande {
  @include botao('grande');
}

.botao-pequeno {
  @include botao('pequeno');
}

📱 Passo 4: Organizando Responsividade

Crie mixins para breakpoints e mantenha media queries junto aos componentes 

// _variables.scss
$breakpoints: (
  'mobile': 576px,
  'tablet': 768px,
  'desktop': 1024px,
  'wide': 1280px
);

// _mixins.scss
@mixin respond-to($breakpoint) {
  @if map-has-key($breakpoints, $breakpoint) {
    @media (min-width: map-get($breakpoints, $breakpoint)) {
      @content;
    }
  } @else {
    @warn "Breakpoint '#{$breakpoint}' não encontrado!";
  }
}

// Uso nos componentes
.container {
  width: 100%;
  padding: 15px;
  
  @include respond-to('tablet') {
    width: 750px;
    padding: 20px;
  }
  
  @include respond-to('desktop') {
    width: 970px;
  }
  
  @include respond-to('wide') {
    width: 1200px;
  }
}

.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 20px;
  
  @include respond-to('tablet') {
    grid-template-columns: repeat(2, 1fr);
  }
  
  @include respond-to('desktop') {
    grid-template-columns: repeat(4, 1fr);
  }
}

⚡ Passo 5: Minificando o CSS Final

Compile o SASS em modo comprimido para produção 

# Modo expandido (desenvolvimento)
sass sass/main.scss css/style.css

# Modo comprimido (produção)
sass sass/main.scss css/style.min.css --style=compressed

# Watch mode com minificação
sass --watch sass/main.scss:css/style.min.css --style=compressed

# Sourcemap para debug
sass sass/main.scss css/style.css --source-map
✅ Resultado: Seu CSS será otimizado, removendo espaços, comentários e quebrando linhas, resultando em um arquivo muito menor e mais rápido!

Antes (50 KB)

.botao {
  padding: 10px 20px;
  background: #3498db;
  color: white;
  border: none;
}

.botao:hover {
  background: #2980b9;
}

Depois (15 KB - Minificado)

.botao{padding:10px 20px;background:#3498db;color:#fff;border:none}.botao:hover{background:#2980b9}

📚 Materiais Complementares e Questionário

💡 Dicas e Boas Práticas

✅ FAÇA

  • Use variáveis para valores repetidos
  • Organize arquivos em pastas lógicas
  • Crie mixins para padrões comuns
  • Limite aninhamento a 3-4 níveis
  • Documente mixins e funções complexas
  • Use nomes descritivos para variáveis
  • Compile em modo comprimido para produção

❌ NÃO FAÇA

  • Aninhar mais de 4 níveis (fica ilegível)
  • Criar variáveis para valores únicos
  • Duplicar código em vez de usar mixins
  • Misturar estilos de componentes diferentes
  • Usar !important (evite ao máximo)
  • Ignorar organização de arquivos
  • Commitar arquivos .css compilados
