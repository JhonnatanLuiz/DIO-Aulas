Módulo 3

Principais Recursos do SASS

💾 Variáveis

Armazene valores que você usa repetidamente (cores, fontes, tamanhos, etc.) 

// Definindo variáveis
$cor-primaria: #3498db;
$cor-secundaria: #2ecc71;
$espacamento: 16px;

// Usando as variáveis
.botao {
  background-color: $cor-primaria;
  padding: $espacamento;
}
💡 Vantagem: Altere a cor em um único lugar e ela muda em todo o projeto!

🪆 Nesting (Aninhamento)

Aninhe seletores para refletir a hierarquia do HTML. 

.nav {
  background: #333;
  
  ul {
    list-style: none;
    
    li {
      margin: 0 10px;
      
      a {
        color: white;
        
        &:hover {  // & = seletor pai
          color: #3498db;
        }
      }
    }
  }
}
⚠️ Cuidado: Não aninhe mais de 3-4 níveis para evitar especificidade excessiva.

🧩 Partials

Arquivos que começam com _ (underline) não são compilados sozinhos. Eles servem para organizar seu código. 

// _header.scss
.header { ... }

// main.scss
@import 'header'; // O underline e a extensão são opcionais

🛠️ Mixins

Blocos de código reutilizáveis que podem receber argumentos. 

@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

.card {
  @include flex-center;
}
