Visão Geral e Pré-processadores

📚 Introdução ao Curso

Bem-vindo ao curso completo de SASS! Neste guia interativo, você vai aprender desde os conceitos básicos até técnicas avançadas para escrever CSS de forma mais eficiente e organizada.

O que você vai aprender:
  • Sintaxe e recursos do SASS/SCSS
  • Variáveis, mixins e funções
  • Estruturas de controle e loops
  • Organização de projetos reais

🤔 O que são Pré-processadores CSS?

Pré-processadores CSS são ferramentas que estendem as capacidades do CSS tradicional, permitindo usar variáveis, funções, aninhamento e muito mais. O código é então compilado para CSS puro que os navegadores entendem.

❌ CSS Tradicional

.header { color: #333; }
.header .nav { color: #333; }
.header .nav a { color: #333; }

✅ Com SASS

$cor-texto: #333;

.header {
  color: $cor-texto;
  .nav {
    color: $cor-texto;
    a { color: $cor-texto; }
  }
}
