🧮 Operações Matemáticas

SASS permite realizar operações matemáticas diretamente no CSS! 

$largura-base: 1000px;
$colunas: 4;
$espacamento: 20px;

.coluna {
  width: ($largura-base / $colunas) - $espacamento; // (1000px / 4) - 20px = 230px
}

🔀 Condicionais (@if, @else)

$tema: 'escuro';

.site {
  @if $tema == 'escuro' {
    background: #1a1a1a;
    color: #fff;
  } @else {
    background: #fff;
    color: #333;
  }
}

🔁 Loops (@for, @each)

@for (Contador)

@for $i from 1 through 3 {
  .col-#{$i} { width: 100% * $i; }
}

@each (Lista)

$cores: red, blue, green;

@each $cor in $cores {
  .bg-#{$cor} { background: $cor; }
}

🐛 Depuração

  • @debug: Exibe valores no console durante a compilação.
  • @warn: Emite avisos sem parar a compilação.
  • @error: Para a compilação e exibe uma mensagem de erro.
