Módulo 5

Convertendo Projeto CSS para SASS

📁 Organização de Módulos

A arquitetura 7-1 pattern é uma das mais populares para organizar projetos SASS.

sass/ ├── abstracts/ (variáveis, mixins, funções) ├── base/ (reset, tipografia) ├── components/ (botões, cards, navbar) ├── layout/ (header, footer, grid) ├── pages/ (estilos específicos de páginas) ├── themes/ (temas claro/escuro) ├── vendors/ (bootstrap, jquery ui) └── main.scss (arquivo principal que importa tudo)

📱 Responsividade com Mixins

Facilite a criação de media queries com mixins reutilizáveis. 

$breakpoints: (
  'mobile': 576px,
  'tablet': 768px,
  'desktop': 1024px
);

@mixin respond-to($breakpoint) {
  @if map-has-key($breakpoints, $breakpoint) {
    @media (min-width: map-get($breakpoints, $breakpoint)) {
      @content;
    }
  }
}

.container {
  width: 100%;
  @include respond-to('desktop') {
    width: 960px;
  }
}

⚡ Minificação do CSS

Para produção, sempre compile seu CSS no modo comprimido para reduzir o tamanho do arquivo. 

sass sass/main.scss css/style.min.css --style=compressed
✅ Resultado: Remove espaços e comentários, reduzindo drasticamente o tamanho do arquivo.
