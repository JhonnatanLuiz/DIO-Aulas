🤔 O que é SASS?

SASS (Syntactically Awesome Style Sheets) é uma extensão do CSS que adiciona poder e elegância à linguagem básica. Ele permite usar variáveis, regras aninhadas, mixins, funções e muito mais, tudo com uma sintaxe totalmente compatível com CSS.

🚀 Por que usar?

  • Organize seu CSS em módulos pequenos e reutilizáveis
  • Economize tempo com mixins e funções
  • Mantenha a consistência visual com variáveis
